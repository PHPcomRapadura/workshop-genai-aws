# Workshop GenAI Development AWS

Inscrições para o **Workshop GenAI Development AWS**, uma promoção da [NuageIT](https://nuageit.com.br/).

Temos somente **10 vagas**. As vagas são preenchidas pela ordem em que os pull requests válidos são aprovados e mesclados automaticamente.

## Regulamento

1. Faça um fork deste repositório.
2. Adicione uma única linha ao final da tabela em [`participantes.md`](participantes.md), usando um e-mail (`| seu-email@exemplo.com |`) ou usuário do Telegram (`| @seu_usuario |`).
3. Abra um pull request para a branch `main` deste repositório.
4. Aguarde a validação automática. Se o contato for válido, não estiver duplicado e ainda houver vaga, o pull request será mesclado automaticamente.

O contato informado será usado pela organização para enviar a licença do Kiro. Usuários do Telegram devem começar com `@` e conter de 5 a 32 letras, números ou sublinhados. Cada pessoa pode ocupar apenas uma vaga. Pull requests incompletos, com contato inválido ou que alterem outros arquivos não reservam vaga.

## Atenção sobre privacidade

O arquivo de participantes e o histórico dos pull requests são públicos. Ao enviar a inscrição, você concorda com a publicação do contato informado e com seu uso pela NuageIT para comunicação relacionada a esta promoção e ao envio da licença do Kiro. Se preferir, use um e-mail ou usuário do Telegram criado especificamente para essa finalidade.

## Critério das vagas

A inscrição só é confirmada quando o pull request é mesclado. O workflow processa as inscrições de forma sequencial e aceita no máximo 10 contatos. Caso duas inscrições sejam abertas ao mesmo tempo, prevalece a primeira que puder ser validada e mesclada sobre a versão mais recente da lista.
