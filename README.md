# Workshop GenAI Development AWS

Inscrições para o **Workshop GenAI Development AWS**, uma promoção da [NuageIT](https://nuageit.com.br/).

Temos somente **10 vagas**. As vagas são preenchidas pela ordem em que os pull requests válidos são aprovados e mesclados automaticamente.

## Regulamento

1. Faça um fork deste repositório.
2. Adicione uma única linha ao final da tabela em [`participantes.md`](participantes.md), usando o formato `| seu-email@exemplo.com |`.
3. Abra um pull request para a branch `main` deste repositório.
4. Aguarde a validação automática. Se o e-mail for válido, não estiver duplicado e ainda houver vaga, o pull request será mesclado automaticamente.

O e-mail informado será usado pela organização para entrar em contato e enviar a licença do Kiro. Cada pessoa pode ocupar apenas uma vaga. Pull requests incompletos, com e-mail inválido ou que alterem outros arquivos não reservam vaga.

## Atenção sobre privacidade

O arquivo de participantes e o histórico dos pull requests são públicos. Ao enviar a inscrição, você concorda com a publicação do e-mail informado e com seu uso pela NuageIT para contato relacionado a esta promoção e ao envio da licença do Kiro. Se preferir, use um endereço criado especificamente para essa finalidade.

## Critério das vagas

A inscrição só é confirmada quando o pull request é mesclado. O workflow processa as inscrições de forma sequencial e aceita no máximo 10 e-mails. Caso duas inscrições sejam abertas ao mesmo tempo, prevalece a primeira que puder ser validada e mesclada sobre a versão mais recente da lista.
